Nimbus gets a Gallery view, sends files in from any app through the Services menu, shares cloud files out, and gives Google Drive a way off the shared sign-in that Google has been slowing down.

## Requirements

- macOS 15 or later, Apple silicon or Intel
- rclone. If none is installed, Nimbus offers to download the official build for your Mac and checks it before use. Share links and backup previews need rclone 1.76 or later.

## Install

From 1.1.0 or later: choose Nimbus > Check for Updates…, or wait for the automatic check if you turned it on.

With Homebrew: `brew trust --tap casavargas/tap && brew tap CasaVargas/tap && brew install --cask nimbus`, or `brew upgrade --cask nimbus` if you installed it that way.

From 1.0.1 or earlier: open the DMG, drag Nimbus to Applications, launch it. The app is signed with a Developer ID certificate and notarized by Apple, so Gatekeeper opens it without warnings. Nothing to redo.

## New

- **Gallery view.** View > as Gallery (⌘3), or the third button in the browser's view switcher. One large preview of the selected item over a filmstrip of the folder. Photos and PDFs up to 20 MB show as pictures; other files keep their icon. Arrow keys move through the folder, Return opens, Space is Quick Look. Only the pictures on screen are fetched.
- **Send to Nimbus.** Select files or folders in Finder or any other app, then choose Services > Send to Nimbus…. Nimbus asks which cloud and folder (it remembers the last one) and copies them there; the copies show in Transfers. If a name is already in that folder, it asks whether to replace it or keep both.
- **Share.** Right-click a cloud file in the browser, or use Share… in the inspector, to send it with Mail, Messages, AirDrop and the rest of the system share menu. Nimbus downloads the file first.
- **Your own Google sign-in for Google Drive.** Google Drive clouds have been signing in through an ID shared by everyone who uses rclone. Google limits that ID, which made folders slow to open or fail with "The request timed out", and rclone is retiring it during 2026. Home now shows a card for each Google Drive cloud that still uses it. Set Up… lists the steps in Google Cloud Console with a link for each, takes the file Google lets you download (or the ID and secret pasted in), and signs you in again. It's free, and one ID works for all your Google Drive clouds.

## Changed

- Opening a folder now waits up to two minutes for a slow service instead of giving up after 30 seconds, and says "Still loading" after 8 seconds.
- rclone's notices and errors are kept in `~/Library/Logs/Nimbus/rclone.log` (up to 1 MB) instead of being discarded.

## Known issues

- After you set up your own Google sign-in, Google shows "Google hasn't verified this app" when you sign in. That is expected for an ID you made yourself: choose Advanced, then continue.
- On a Google Drive cloud still using the shared sign-in, choosing a folder in a sheet and Send to Nimbus's check for existing names can still time out after 30 seconds. Try again, or set up your own sign-in.
- Share from the browser offers files, not folders.
- Some Google Docs, Sheets and Slides files show an enormous size in Finder. Nothing is downloaded; the size just isn't known until the file is exported.
- After quitting Nimbus in the middle of a backup, the next run can fail once on a leftover temporary file. Run it again and it completes.
- A backup started by hand and cut off by quitting is not marked as stopped; its row still shows the previous run.
