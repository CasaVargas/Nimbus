Nimbus moves files through Finder faster and with less memory, and OneDrive gets quicker uploads and search.

## Requirements

- macOS 15 or later, Apple silicon or Intel
- rclone. If none is installed, Nimbus offers to download the official build for your Mac and checks it before use. Share links and backup previews need rclone 1.76 or later.

## Install

From 1.1.0 or later: choose Nimbus > Check for Updates…, or wait for the automatic check if you turned it on.

With Homebrew: `brew trust --tap casavargas/tap && brew tap CasaVargas/tap && brew install --cask nimbus`, or `brew upgrade --cask nimbus` if you installed it that way.

From 1.0.1 or earlier: open the DMG, drag Nimbus to Applications, launch it. The app is signed with a Developer ID certificate and notarized by Apple, so Gatekeeper opens it without warnings. Nothing to redo.

## Faster

- **Copying files in and out of Finder.** rclone now copies the file itself instead of passing every byte through Nimbus's Finder extension. A file is no longer held whole in memory, large downloads (over 256 MB) arrive over several connections, and uploads to OneDrive skip an extra temporary copy. A long transfer is no longer cut off after 15 minutes, cancelling in Finder stops it, and uploaded files keep their modification date. If the direct copy can't be used on your Mac, Nimbus falls back to the old way.
- **OneDrive uploads.** Large files go up in 40 MB pieces instead of 10 MB. In testing, a 256 MB upload took about 30% less time.
- **OneDrive search.** Search reads the whole drive in one go from OneDrive's change list, instead of opening folders one by one, and is no longer limited to 10 levels deep. The same applies to other clouds that can list everything at once, such as Amazon S3 and Google Drive. OneDrive's change list always starts at the top of the drive, so an encrypted folder or alias inside a OneDrive folder, or a OneDrive cloud set to start in a folder, is still searched folder by folder, up to 10 levels deep.
- **Coming back to a cloud.** Nimbus keeps a cloud's connection ready for 30 minutes after you last used it, up from 5, so the next folder opens without setting it up again.

For OneDrive, Nimbus sets rclone's `delta` and `chunk_size` options when it starts rclone. They take precedence over the same options in your rclone configuration. To use your own values, set `RCLONE_ONEDRIVE_DELTA` or `RCLONE_ONEDRIVE_CHUNK_SIZE` in the environment Nimbus is started from.

## Known issues

- Sharing more than 2 GB of items that have to be copied first (photos from Photos, files inside another app's own storage) is refused with a message. Use Services > Send to Nimbus… in Finder for those.
- After you set up your own Google sign-in, Google shows "Google hasn't verified this app" when you sign in. That is expected for an ID you made yourself: choose Advanced, then continue.
- On a Google Drive cloud still using the shared sign-in, choosing a folder in a sheet and Send to Nimbus's check for existing names can still time out after 30 seconds. Try again, or set up your own sign-in.
- Some Google Docs, Sheets and Slides files show an enormous size in Finder. Nothing is downloaded; the size just isn't known until the file is exported.
- After quitting Nimbus in the middle of a backup, the next run can fail once on a leftover temporary file. Run it again and it completes.
- A backup started by hand and cut off by quitting is not marked as stopped; its row still shows the previous run.
