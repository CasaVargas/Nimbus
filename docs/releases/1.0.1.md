Nimbus now runs on Intel Macs. Every earlier build, 1.0.0 included, ran only on Apple silicon. Nothing else changed since 1.0.0.

## Requirements

- macOS 15 or later, Apple silicon or Intel
- rclone. If none is installed, Nimbus offers to download the official build for your Mac and checks it before use. Share links and backup previews need rclone 1.76 or later.

## Install

Open the DMG, drag Nimbus to Applications, launch it. The app is signed with a Developer ID certificate and notarized by Apple, so Gatekeeper opens it without warnings.

Updating from 1.0.0: replace the app. Nothing to redo.

## Fixed

- **Intel Macs.** The app and its Finder extension are now universal (Apple silicon and Intel). Earlier builds were Apple silicon only, so they would not open on an Intel Mac.

Everything new in 1.0 is described in [its release notes](https://github.com/CasaVargas/Nimbus/releases/tag/v1.0.0).

## Known issues

- After quitting Nimbus in the middle of a backup, the next run can fail once on a leftover temporary file. Run it again and it completes.
- A backup started by hand and cut off by quitting is not marked as stopped; its row still shows the previous run.
