Nimbus 1.0. Search across clouds, encrypted folders, folder compare, version history, Shortcuts, and backups that run while Nimbus is closed. Nimbus is free, source and signed builds alike.

## Requirements

- macOS 15 or later, Apple silicon or Intel
- rclone. If none is installed, Nimbus offers to download the official build and checks it before use. Share links and backup previews need rclone 1.76 or later.

## Install

Open the DMG, drag Nimbus to Applications, launch it. The app is signed with a Developer ID certificate and notarized by Apple, so Gatekeeper opens it without warnings.

Updating from 0.10.1: replace the app.

## New

- **Search across clouds.** Find files by name in every cloud at once.
- **New Encrypted Folder.** A guided setup for a folder whose contents are encrypted before they leave this Mac, inside any cloud you already use.
- **Compare Folders.** Pick two folders, on any clouds or this Mac, and see what is only on one side, what differs, and what matches. Read-only: nothing is changed.
- **Version history** in the inspector for S3 and Backblaze B2. List the versions the service kept of a file, then restore or download one.
- **Verified transfers.** Each finished transfer says whether rclone checked it by checksum or only by size, and flags a checksum mismatch.
- **Backups while Nimbus is closed.** Turn it on and a small background agent runs scheduled backups without the app open.
- **Shortcuts.** Run Backup, Copy Share Link and Keep Downloaded as Shortcuts actions.
- **Lock with Keychain.** Optionally encrypt your sign-ins and keys with a password kept in the Keychain (Settings > Advanced).
- **Finder badges** for files kept downloaded and uploads that failed.
- **Faster Finder updates.** Changes made elsewhere show up within about a minute in folders you are working in. Other folders still refresh every ten minutes.

## Known issues

- After quitting Nimbus in the middle of a backup, the next run can fail once on a leftover temporary file. Run it again and it completes.
- A backup started by hand and cut off by quitting is not marked as stopped; its row still shows the previous run.

## Not yet
