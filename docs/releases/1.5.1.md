The menu bar list of clouds now scrolls when you have more clouds than fit on the screen.

## Requirements

- macOS 15 or later, Apple silicon or Intel
- rclone. If none is installed, Nimbus offers to download the official build for your Mac and checks it before use. Share links and backup previews need rclone 1.76 or later.

## Install

From 1.1.0 or later: choose Nimbus > Check for Updates…, or wait for the automatic check if you turned it on.

With Homebrew: `brew trust --tap casavargas/tap && brew tap CasaVargas/tap && brew install --cask nimbus`, or `brew upgrade --cask nimbus` if you installed it that way.

From 1.0.1 or earlier: open the DMG, drag Nimbus to Applications, launch it. The app is signed with a Developer ID certificate and notarized by Apple, so Gatekeeper opens it without warnings. Nothing to redo.

## Fixed

- **The menu bar list ran off the screen.** With many clouds (28 in the report), the list in the menu bar window grew past the bottom of the screen, and the clouds at the end could not be reached. The list now stops above the bottom of the screen and scrolls, with Recent activity, Add Cloud… and Open Nimbus still in view. With only a few clouds the window looks as before. ([#154](https://github.com/CasaVargas/Nimbus/issues/154))

Everything new in 1.5 is described in [the 1.5.0 release notes](https://github.com/CasaVargas/Nimbus/releases/tag/v1.5.0).

## Known issues

- Sharing more than 2 GB of items that have to be copied first (photos from Photos, files inside another app's own storage) is refused with a message. Use Services > Send to Nimbus… in Finder for those.
- After you set up your own Google sign-in, Google shows "Google hasn't verified this app" when you sign in. That is expected for an ID you made yourself: choose Advanced, then continue.
- On a Google Drive cloud still using the shared sign-in, choosing a folder in a sheet and Send to Nimbus's check for existing names can still time out after 30 seconds. Try again, or set up your own sign-in.
- Some Google Docs, Sheets and Slides files show an enormous size in Finder. Nothing is downloaded; the size just isn't known until the file is exported.
- After quitting Nimbus in the middle of a backup, the next run can fail once on a leftover temporary file. Run it again and it completes.
- A backup started by hand and cut off by quitting is not marked as stopped; its row still shows the previous run.
