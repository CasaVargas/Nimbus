Nimbus can now update itself. This is the last version you install by hand.

## Requirements

- macOS 15 or later, Apple silicon or Intel
- rclone. If none is installed, Nimbus offers to download the official build for your Mac and checks it before use. Share links and backup previews need rclone 1.76 or later.

## Install

Open the DMG, drag Nimbus to Applications, launch it. The app is signed with a Developer ID certificate and notarized by Apple, so Gatekeeper opens it without warnings.

Updating from 1.0.1 or earlier: replace the app one more time. Nothing to redo. From 1.1.0 on, Nimbus installs new versions itself.

## New

- **Updates from inside the app.** Choose Nimbus > Check for Updates…, or turn on "Check for updates automatically" in Settings > General. Nimbus shows what changed, then downloads, checks and installs the new version and reopens.
- **Off until you say so.** Nimbus does not look for updates on its own unless you turn that on. The second time you open it, it asks once. A check is a single request to GitHub for the latest release; nothing about you or your Mac is sent.
- **Signed.** An update is installed only if it carries Nimbus's update signature, which is checked before the download is opened.

Updates use [Sparkle](https://sparkle-project.org), the updater most Mac apps outside the App Store use. It is the one third-party package in Nimbus.

## Known issues

- After quitting Nimbus in the middle of a backup, the next run can fail once on a leftover temporary file. Run it again and it completes.
- A backup started by hand and cut off by quitting is not marked as stopped; its row still shows the previous run.

## Checksum

```
SHA-256 Nimbus-1.1.0.dmg
(filled in when the signed DMG is built)
```
