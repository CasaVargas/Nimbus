Adding a cloud opens one window again. Nothing else changed since 1.1.0.

## Requirements

- macOS 15 or later, Apple silicon or Intel
- rclone. If none is installed, Nimbus offers to download the official build for your Mac and checks it before use. Share links and backup previews need rclone 1.76 or later.

## Install

From 1.1.0: choose Nimbus > Check for Updates…, or wait for the automatic check if you turned it on.

From 1.0.1 or earlier: open the DMG, drag Nimbus to Applications, launch it. The app is signed with a Developer ID certificate and notarized by Apple, so Gatekeeper opens it without warnings. Nothing to redo.

## Fixed

- **One Add Cloud window.** With clouds already added, Add Cloud opened a stack of identical windows, one per cloud plus one, so finishing or cancelling showed another one underneath. It now opens one. The same fix applies to Edit, Remove, Import from rclone.conf and New Encrypted Folder in the sidebar.

Everything new in 1.1 is described in [its release notes](https://github.com/CasaVargas/Nimbus/releases/tag/v1.1.0).

## Known issues

- After quitting Nimbus in the middle of a backup, the next run can fail once on a leftover temporary file. Run it again and it completes.
- A backup started by hand and cut off by quitting is not marked as stopped; its row still shows the previous run.

```
SHA-256 Nimbus-1.2.0.dmg
(filled in when the signed DMG is built)
```
