A security fix. Update now. Nothing else changed since 1.2.1.

## Requirements

- macOS 15 or later, Apple silicon or Intel
- rclone. If none is installed, Nimbus offers to download the official build for your Mac and checks it before use. Share links and backup previews need rclone 1.76 or later.

## Install

From 1.1.0 or later: choose Nimbus > Check for Updates…, or wait for the automatic check if you turned it on.

From 1.0.1 or earlier: open the DMG, drag Nimbus to Applications, launch it. The app is signed with a Developer ID certificate and notarized by Apple, so Gatekeeper opens it without warnings. Nothing to redo.

## Security

- **The rclone connection now needs a password.** Nimbus talks to rclone through a connection on your Mac. Until now that connection accepted requests from any app on the Mac, and could be reached by web pages in some browsers, so they could read your clouds' sign-in details and files while Nimbus was running. Nimbus now creates a new random password for it every time it starts, and only Nimbus and its Finder extension have it. Details: [GHSA-c784-cjq9-53gf](https://github.com/CasaVargas/Nimbus/security/advisories/GHSA-c784-cjq9-53gf).

  If you think your sign-in details may have been exposed, sign in again to each cloud, or change its password or access keys.

Everything new in 1.2 is described in [its release notes](https://github.com/CasaVargas/Nimbus/releases/tag/v1.2.0).

## Known issues

- After quitting Nimbus in the middle of a backup, the next run can fail once on a leftover temporary file. Run it again and it completes.
- A backup started by hand and cut off by quitting is not marked as stopped; its row still shows the previous run.
