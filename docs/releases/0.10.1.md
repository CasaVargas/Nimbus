Fixes the Finder features that did not work in 0.10.0. If you installed 0.10.0, update.

## Fixed

- **Keep Downloaded, Copy Share Link in Finder, and changes made elsewhere showing up in Finder now work in the released app.** In 0.10.0 (and 0.9.1) the part of Nimbus that runs inside Finder could not read the data it shares with the app, so these three did nothing. Browsing, opening, uploading and thumbnails were not affected.
- The Finder extension now carries the same version number as the app.

## Updating

Replace the app. On first launch Nimbus asks Finder to rebuild each cloud once:

- files you had downloaded through Finder are fetched again when you next open them;
- a folder catches up the next time you open it in Finder.

## Requirements

- macOS 15 or later, Apple silicon or Intel
- rclone on your PATH (`brew install rclone`); the path is configurable in Settings > Advanced. Share links and backup previews need rclone 1.76 or later.

## Install

Open the DMG, drag Nimbus to Applications, launch it. The app is signed with a Developer ID certificate and notarized by Apple, so Gatekeeper opens it without warnings.

## Known issues

- After quitting Nimbus in the middle of a backup, the next run can fail once on a leftover temporary file. Run it again and it completes.
- A backup started by hand and cut off by quitting is not marked as stopped; its row still shows the previous run.
- Scheduled backups run only while Nimbus is open (the menu bar counts). Turn on Open at Login to keep them running.
- Changes made elsewhere reach Finder within about ten minutes, not at once.

Everything new in 0.10.0 is described in [its release notes](https://github.com/CasaVargas/Nimbus/releases/tag/v0.10.0).
