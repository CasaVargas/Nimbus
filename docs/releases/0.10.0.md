A new look, scheduled backups, and the Finder features people expect from a cloud app. Nimbus is free, source and signed builds alike.

## Requirements

- macOS 15 or later, Apple silicon or Intel
- rclone on your PATH (`brew install rclone`); the path is configurable in Settings > Advanced. Share links and backup previews need rclone 1.76 or later.

## Install

Open the DMG, drag Nimbus to Applications, launch it. The app is signed with a Developer ID certificate and notarized by Apple, so Gatekeeper opens it without warnings.

Updating from 0.9.1: replace the app. Finder re-reads each cloud once after the update, so a large cloud can be slow to list for a few minutes.

## New

- **A new look.** A sky backdrop, glass sidebar and cards, each cloud in its own colour, and Liquid Glass on macOS 26 and later. Light and Dark both follow the Appearance setting.
- **Home.** Free space across all your clouds, a storage ring, a card per cloud with its status in plain words, recent activity, and a prompt when a cloud needs you to sign in again.
- **Backups.** Save a backup from a folder on this Mac, or a cloud, to another cloud or folder. Every backup shows a preview of what it will copy, replace and remove before it runs. Run it by hand or every hour, day or week. Replaced and removed files are kept in a versions folder for as long as you choose, and a removal limit stops a run that would delete more than you expect.
- **Keep Downloaded.** Pin a file or folder from Finder's menu or the inspector so it stays on this Mac; Allow Removing Download undoes it.
- **Share links.** Copy Share Link in Finder and the inspector, for services that make links. Where the service supports it you can choose when the link expires and stop sharing.
- **Finder thumbnails** for photos and PDFs that are still in the cloud.
- **Changes made elsewhere show up in Finder** without re-importing the cloud.
- **Menu bar panel** with each cloud's status, running transfers and recent activity.
- **Add Cloud** walks through setup in plain words, with one-click sign-in for the services that offer it.
- **"On this Mac" column** in the file list, and a Nimbus symbol for its locations in Finder's sidebar.

## Fixed

- Home no longer counts pooled storage twice in free space.
- Answering a setup question after signing in no longer restarts the walk-through.
- A finished transfer no longer waits on the notification permission prompt, which could leave a backup showing "Backing up… 0%" for good.
- "Save and Preview…" always previews the backup you just saved.

## Known issues

- After quitting Nimbus in the middle of a backup, the next run can fail once on a leftover temporary file. Run it again and it completes.
- A backup started by hand and cut off by quitting is not marked as stopped; its row still shows the previous run.
- Scheduled backups run only while Nimbus is open (the menu bar counts). Turn on Open at Login to keep them running.
