Three directions for Nimbus

Each direction is a different answer to one question: what should someone see when they open a cloud storage app on their Mac? All three use the same native parts (Liquid Glass toolbar, floating sidebar, system type), the same plain vocabulary, and the same sample data, so the differences are about layout and priorities, not paint.

PlacesEvery cloud is a drive in one Finder-grade window

Clouds sit in the sidebar the way disks sit in Finder. Pinned folders from any cloud sit beside them. The window is a fast file browser first: thumbnails, an inspector that explains where a file lives, and one search box that looks in every cloud at once.

Feels like
Finder, if every cloud were plugged in
Best for
People who move and find files across several clouds every day
Gives up
Someone who only wanted their Google Drive in Finder still meets a file browser first. Account health is a glyph, not a sentence.
From today
Closest to the current Volumes build. Mostly a sidebar, inspector, and search change.

HomeA calm overview that answers "is everything okay?" first

The window opens on Home, styled after the Storage pane in System Settings: one bar for everything you store, one line per cloud in plain words, and at most one problem with the button that fixes it. Files are one click deeper, inside each cloud.

Feels like
System Settings › Storage, for every cloud you use
Best for
Anyone. Especially people who don't know what rclone, a remote, or a mount is.
Gives up
Power users take one extra click to reach files. Suggestions need care so they never read as nagging.
From today
New Home screen plus a guided Add Cloud sheet. The Volumes pane stays as each cloud's detail page.

CompanionFinder is the file browser; Nimbus lives in the menu bar

Most people never want another file browser. They want their clouds under Locations in Finder and a quiet signal that everything is working. Nimbus becomes a menu bar companion with a small settings-style window for each cloud. The full browser is still there for cross-cloud copies, one menu item away.

Feels like
iCloud Drive: it's just there, in Finder
Best for
People who set it up once and forget it. The biggest audience, and the most "Apple would have shipped this".
Gives up
Nimbus is less visible, so less of its polish is seen. Depends on File Provider being rock solid.
From today
Builds on the existing menu bar extra and Finder integration. Settings-style cloud pages are new.

Applies to every direction: say it like a person

The single biggest ease-of-use win isn't layout. It's removing rclone's vocabulary from every screen a non-technical person sees.

My recommendation: Home as the spine, Companion around it

Make Home (direction 2) what the window opens to, and keep today's Volumes pane as the page behind each cloud row, so power users lose nothing. Then ship the Companion menu bar popover (direction 3) as the always-on status surface, because "is it working?" is a question people ask far more often than "where is my file?".

Places (direction 1) is the most impressive screenshot, but it competes with Finder head-on. Borrow its two best parts instead: search across all clouds, and the inspector line that says where a file lives and whether it's on this Mac.
